# CityMETER: School

**นักเรียนกระจุกอยู่ตรงไหน และรอบแปลงมีโรงเรียนแบบไหน** — เดโมแผนที่ 3 มิติของสถานศึกษาทั่วประเทศไทย ที่อ่านนักเรียนที่ทะเบียนบันทึกเป็นยอดต่อเขต/อำเภอ พร้อมประเภทและสังกัด ระดับชั้น ค่าเรียนตามประกาศ ผลประเมิน สมศ. ระยะถึงสถานีรถไฟฟ้า โรงเรียนใกล้เคียงแบบเดียวกัน สถานที่เรียนเสริม (กวดวิชา ภาษา ศิลปะ พัฒนาการเด็ก) และที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/school/
- ระบบจริงของ CityMETER: https://landometer.com/v3/citymeter?d=school
- รุ่น 0.2.0 · 6 พฤศจิกายน 2569 · เพิ่มชั้นเรียนเสริมจากแท็บ 27–29 ของชีตวิจัยเดียวกัน (อ่าน 6 พ.ย. 2569, ทะเบียน สช. ตรวจแหล่ง 31 ต.ค. 2569) · ข้อมูลสถานศึกษาเหมือนรุ่น 0.1.0 (ตรวจแหล่ง 31 ต.ค. อ่าน 5 พ.ย. 2569 และอ่านซ้ำ 6 พ.ย. ค่าเท่าเดิม)
- โค้ดต่อยอดจาก CityMETER · Hotel 0.3.6 (https://github.com/montri-th/hotel @177e592)

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **12% ของนักเรียนกรุงเทพมหานคร (106,163 จาก 916,683 คน) อยู่ใน 3 เขต — ลาดกระบัง สายไหม บางกะปิ** · ใกล้รถไฟฟ้า ≤ 500 ม.: 3 เขตนี้ 1% (620/79,083 คน) เขตอื่น 17% (112,216/648,859) · อันดับ 1 นอกกรุงเทพฯ คือเมืองนครราชสีมา 93,597 คน มากกว่าทุกเขตของกรุงเทพฯ

เรียนเสริม (มาตรวัดที่ 3): **22% ของสถานที่เรียนเสริมกรุงเทพมหานคร (207 จาก 960 แห่ง) อยู่ใน 3 เขต — ปทุมวัน คลองเตย ประเวศ** · แห่งที่มีหมุดใกล้รถไฟฟ้า ≤ 500 ม.: 3 เขตนี้ 68% (39/57) เขตอื่น 34% (88/262) · อันดับ 1 นอกกรุงเทพฯ คือเมืองเชียงใหม่ 95 แห่ง

> ชุดข้อมูล CityMETER School จาก CityMETER School 2569 (สช. · สมศ. · ประกาศค่าเรียนของโรงเรียน) และทะเบียนโรงเรียนนอกระบบ สช. (เรียนเสริม) · ตรวจ 31 ต.ค. 2569 · ขอบเขต เขต/อำเภอของ CityMETER ทั่วประเทศ · วิธีนับ: `DATA_METHOD.md`

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/shell/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกแบบ 3 มิติ:** โฟกัสเขต/อำเภอที่มีนักเรียนมากที่สุด (ไม่เกิน 3) ของจังหวัดที่มีนักเรียนระดับเขตมากที่สุด บอกสัดส่วน ตัวตั้ง ตัวหาร สัดส่วนใกล้รถไฟฟ้าเทียบส่วนอื่นของจังหวัด และพื้นที่ที่มากที่สุดนอกจังหวัด — ไม่ตัดผ่านค่าที่เท่ากัน และไม่โฟกัสทุกเขตของจังหวัด
- **นักเรียน | สถานศึกษา | เรียนเสริม:** สลับมาตรวัดในคำอธิบายแผนที่ แผนที่ ป้าย ข้อค้นพบ อันดับ และกราฟเปลี่ยนพร้อมกัน (สเกล `li.supply` สำหรับนักเรียน และ `count` สำหรับแห่ง ครบ 41 ระดับของ LDS)
- **เรียนเสริม (0.2.0):** 3,495 แห่งตามแท็บ `27_LEARNING_SERVICES` — รหัสโรงเรียนนอกระบบของ สช. ที่ทีมวิจัยจัดเป็นกวดวิชา ภาษา ศิลปะ หรือพัฒนาการเด็ก และจุดที่ผู้ให้บริการยืนยัน · นับแยกจากสถานศึกษา ไม่บวกรวม · ระดับเขต/อำเภอตามรหัสในทะเบียน · หมุดวงแหวนเฉพาะ 680 แห่งที่จุดในทะเบียนอยู่ในเขตที่ระบุ · กดบริการเพื่อดูเฉพาะบริการนั้น · หน้าโรงเรียน เขต และสถานีบอกเรียนเสริมในเขตเดียวกันและที่มีหมุดรอบ 1 กม. (หรือ 500 ม. รอบสถานี) · หน้าเรียนเสริมบอกโรงเรียนรอบ 1 กม.
- **ประเภทและสังกัด:** 8 ประเภท (สพฐ. · ท้องถิ่นและกรุงเทพฯ · เอกชน · นานาชาติ · อาชีวะ · สกร. · ศูนย์พัฒนาเด็กเล็ก · รัฐอื่น) ด้วยสีและรูปทรงของ LDS · 16 สังกัดตามทะเบียน กดสังกัดเพื่อดูทุกแห่งของสังกัดนั้น
- **ระดับชั้นและขนาด:** อนุบาล · ประถม · ม.ต้น · ม.ปลาย/ปวช. ตามรหัสชั้นของทะเบียน (มีเฉพาะโรงเรียน สพฐ. ที่เหลืออยู่ในกลุ่ม “ไม่ทราบระดับชั้น”) · ขนาดตาม SchoolSize ของ production
- **สถานีรถไฟฟ้า (CityMETER Transit):** วงกลมเล็กบนแผนที่ กดเพื่อดูสถานศึกษาในรัศมีระยะตรง 500 ม. พร้อมวงรัศมีบนแผนที่ และลิงก์ไปสถานีเดียวกันใน CityMETER Transit
- **ขนาดสัญลักษณ์ตามจำนวนนักเรียน:** พื้นที่ของสัญลักษณ์เพิ่มตามนักเรียนที่บันทึก สีและรูปทรงยังบอกประเภท วงโปร่ง = ไม่ทราบจำนวนนักเรียน
- **ชื่อโรงเรียนกลางจอ:** ตั้งแต่ระดับไซต์ ชื่อสั้นของโรงเรียนที่นักเรียนมากและค่าเรียนสูงก่อน ไม่เกิน 9 ป้าย (มือถือ 5) ชี้แล้วเห็นการ์ดไอคอน: ประเภท นักเรียน ระดับชั้น สังกัด ค่าเรียน ภูมิประเทศ
- **โรงเรียนหนึ่งแห่ง:** กดโรงเรียนที่มีพิกัด แผนที่เปลี่ยนเป็น 3 มิติและเปิดมุมมองอาคาร 2-point perspective · นักเรียน ระดับชั้น ครู ห้องเรียน สังกัด **ค่าเรียนต่อปีรายชั้นตามประกาศ** (86 แห่ง) **นักเรียนย้อนหลังรายภาคเรียน** (สช. 2565–2567) **ผลประเมิน สมศ.** พร้อมปี หลักสูตรและการรับรอง สถานีที่ใกล้ที่สุด ภูมิประเทศ · **คู่เทียบ** (ประเภทเดียวกัน · ระดับชั้นเดียวกัน · ≤ 2 กม.)
- **อาคารรายพื้นที่:** ใช้หน่วยอาคารของ CityMETER · Hotel — อปท. (กรุงเทพฯ รายเขต) ที่ประเมินแล้วใช้ CityMETER Building V4 เมื่อมีอาคารมากกว่า OpenStreetMap ตั้งแต่ 15% ที่เหลือใช้ OSM
- **ภาษา:** สั้น ใช้ไอคอนและกราฟแท่งเล็กแทนประโยค ไม่มีคำเตือนบนหน้าจอ ทุกหน้าจบด้วยบรรทัดที่มาและลิงก์ “วิธีนับ”
- **ถามต่อใน Google:** ทุกมุมมองมีปุ่มถาม Google AI ด้วยคำถามที่ตรงกับสิ่งที่กำลังดู (เช่น โรงเรียนนี้เปิดรับชั้นไหน ค่าเทอมปีนี้) เปิด Google Search ที่ AI Overview ตอบทันทีด้านบน พร้อม Google Maps และ Street View เมื่อมีพิกัด · คำตอบของ Google ไม่ถูกนำมาเป็นข้อมูลในหน้านี้
- **มือถือ:** ข้อค้นพบกับคำอธิบายแผนที่รวมเป็นแถบเดียวด้านล่าง แผงข้อมูลเปิดตรงโรงเรียนหรือพื้นที่ที่เลือก
- **เส้นทาง:** ประเทศไทย › จังหวัด › เขต/อำเภอ ใช้รหัสเดียวกับ CityMETER production และเปิดพื้นที่เดียวกันในระบบจริงได้ (`?d=school`)
- **ลิงก์ตรง:** `?metric=count` · `?metric=learning` · `?metric=learning&service=tutor` · `?learn=<id>` · `?area=1039` · `?areas=1011,1042,1006` · `?areas=all` · `?province=NMA` · `?group=international` · `?level=kinder` · `?level=unknown` · `?size=z3` · `?aff=113` · `?school=<id>` · `?station=<id>` · `?view=affs` · `?view3d=0`

## ข้อมูล

- `data/schools.json` — 40,828 สถานศึกษาจากชีตวิจัย (ไม่เผยแพร่ชีตหรือเซลล์ของชีต) — `scripts/build-data.py` (อ่านชีตด้วย `scripts/export-sheet-tabs.js` + `scripts/decode-sheet-payload.py`)
- `data/learning.json` — 3,495 สถานที่เรียนเสริมจากแท็บ 27–29 ของชีตเดียวกัน (ไม่มีที่อยู่ ไม่มีรหัส สช. เป็นฟิลด์ หมุดเฉพาะที่ผ่านการตรวจเขต) — `scripts/build-learning.py`
- `data/area-index.json`, `data/frames/{CODE}.json`, `data/provinces.geojson` — เขต/อำเภอและจังหวัดของ CityMETER production — `scripts/build-boundaries.py`
- `data/boundary-receipts.json` — ใบรับของทุก response จาก production base info — `scripts/build-receipts.py`
- `data/building-units/` — แหล่งอาคารราย อปท./เขต จาก CityMETER · Hotel — `scripts/adapt-building-units.py`
- วิธีทั้งหมด ข้อจำกัด และงานวิจัยที่ต้องตามต่อ: `DATA_METHOD.md` · กลยุทธ์ผลิตภัณฑ์: `PRODUCT_STATEMENT.md` · สำหรับนักพัฒนา: `handoff/START_HERE.md` · สำหรับ agent: `llms.txt`
