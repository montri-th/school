## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** นักเรียนที่ทะเบียนบันทึกกระจุกอยู่เขต/อำเภอใด มากแค่ไหนเมื่อเทียบกับทั้งจังหวัด ใกล้สถานีรถไฟฟ้าที่เปิดแล้วแค่ไหนเมื่อเทียบกับเขตอื่น และนอกจังหวัดนั้นมีมากที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ชีตตรวจ 31 ต.ค. 2569, รุ่น 0.1.0): **“12% ของนักเรียนกรุงเทพมหานคร อยู่ใน 3 เขตนี้”** ลาดกระบัง · สายไหม · บางกะปิ — 106,163 จาก 916,683 คน · แท่ง “ใกล้รถไฟฟ้า ≤ 500 ม.”: 3 เขตนี้ 1% (620/79,083) · เขตอื่น 17% (112,216/648,859) ฐานอยู่ในคำอธิบายของแท่ง · ข้อค้นพบรอง “อันดับ 1 นอกกรุงเทพมหานคร: อำเภอเมืองนครราชสีมา นครราชสีมา 93,597 คน · มากกว่าทุกเขตของกรุงเทพมหานคร” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 เขตนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth `li.supply` สัญลักษณ์สถานศึกษาตามประเภท (ขนาดตามจำนวนนักเรียน เฉพาะแถวที่มีจุด) สถานีรถไฟฟ้าเป็นวงกลมเงียบ และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ

**One useful action:** “ดูทุกพื้นที่” (`?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) · สลับ “นักเรียน | สถานศึกษา” ในคำอธิบายแผนที่: ข้อค้นพบเปลี่ยนเป็น “21% ของสถานศึกษานครราชสีมา อยู่ใน 3 อำเภอนี้” (เมืองนครราชสีมา · ปากช่อง · ด่านขุนทด — 382 จาก 1,786 แห่ง) และซ่อนบรรทัดรถไฟฟ้าเพราะไม่มีสถานศึกษาใกล้สถานีที่เปิดแล้วในจังหวัดนั้น

## Evidence cue and calculation

แหล่ง: `data/schools.json` (40,828 แถว; 10,134,747 คนจาก 40,338 แห่งที่ทราบจำนวนนักเรียน) และ `data/area-index.json` (928 เขต/อำเภอ) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| เขต | รหัส | นักเรียน |
|---|---|---:|
| ลาดกระบัง | `1011` | 40,309 |
| สายไหม | `1042` | 33,427 |
| บางกะปิ | `1006` | 32,427 |

จังหวัดที่นำ = จังหวัดที่มีนักเรียนที่ระบุเขต/อำเภอได้มากที่สุด (กรุงเทพมหานคร 916,683 คน) สัดส่วน = 106,163 ÷ 916,683 = 12% ทุกแถวระบุเขตตามทะเบียน ตัวหารจึงเท่ากับยอดทั้งจังหวัด 42 แห่งในกรุงเทพฯ ที่ไม่ทราบจำนวนนักเรียนไม่อยู่ในทั้งตัวตั้งและตัวหาร (อยู่ใน “วิธีนับ”) สัดส่วนใกล้รถไฟฟ้านับเฉพาะนักเรียนของสถานศึกษาที่มีพิกัด ฐานทั้งสองฝั่งอยู่ในคำอธิบายของแท่ง

**ไม่ตัดผ่านค่าเท่ากัน และไม่โฟกัสทุกเขต:** ถ้าเขตลำดับถัดไปมีค่าเท่ากับเขตสุดท้ายที่แสดง โฟกัสเหลือเฉพาะเขตที่มากกว่า ถ้าทุกเขตเท่ากันข้อค้นพบเปลี่ยนเป็น “กระจาย” จังหวัดที่มีเขตที่มีค่าไม่เกิน 3 เขตโฟกัสเฉพาะ N − 1 เขตบนสุด

## States

| State | ผลบนหน้าจอ |
|---|---|
| โหลด | การ์ดเปิดเว็บ (`js/shell/launch.js`) จนข้อมูลพร้อม |
| ไม่พบตามตัวกรอง | “ไม่พบสถานศึกษาตามตัวกรองนี้” + ล้างตัวกรอง |
| เขตที่ไม่มีสถานศึกษาตามตัวกรอง | measured zero ของชุดข้อมูลนี้ + “ดูพื้นที่ที่พบ” |
| ไม่ทราบจำนวนนักเรียน | นับเป็นแห่ง ไม่นับเป็น 0 คน; ช่องตัวเลข “—”; เขตที่ไม่ทราบทั้งหมดเป็นลายทแยง (no data) |
| ไม่ทราบระดับชั้น | แท่ง “ไม่ทราบ” และตัวเลือก “ไม่ทราบระดับชั้น” ในตัวกรอง; คู่เทียบใช้ประเภทอย่างเดียว |
| แผนที่โหลดไม่ได้ | ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ พร้อมปุ่มลองใหม่ |
| ขอบเขตจังหวัดโหลดไม่ได้ | รายงานและลองใหม่เมื่อขอครั้งถัดไป แผงไม่พึ่งขอบเขต |
| เลือกโรงเรียนที่มีพิกัด | แผนที่เปลี่ยนเป็น 3 มิติ กล้อง 2-point ที่อาคารที่หมุดอยู่ในขอบ (“อาคารของสถานศึกษา”) |
| หมุดไม่อยู่ในขอบอาคาร | กล้อง 2-point ที่อาคารใกล้หมุดที่สุดภายใน 300 ม. (ไม่มีก็โหลดถึง 800 ม.) หมุดอยู่ในภาพ ป้าย “อาคารใกล้หมุด” — ไม่นับใน “สถานศึกษาในอาคารนี้” |
| ไม่มีอาคารบนแผนที่ในระยะ 800 ม. | กล้อง 2-point ที่พื้นที่รอบหมุด (กล่อง 90 ม.) |
| โรงเรียนประกาศปิด | ชิป “ประกาศปิด <วันที่>” ก่อนตัวเลข ลิงก์ประกาศใน “ที่มาและพิกัด” |
| เรียนเสริมไม่พบตามตัวกรอง | “ไม่พบสถานที่เรียนเสริมตามตัวกรองนี้” + ล้างตัวกรอง; เขตที่ไม่มีเป็น measured zero |
| สถานที่เรียนเสริมไม่มีหมุด | นับในเขต/อำเภอตามทะเบียน ชิป “ไม่มีหมุด” และเหตุใน “ที่มาและพิกัด” (ทะเบียนไม่มีพิกัด · จุดอยู่นอกเขต/อำเภอหรือจังหวัดที่ทะเบียนระบุ · ค่าพิกัดใช้ไม่ได้) |
